补充：编译期踩坑记录文档 + Logos 生成器可选开关

新增 Docs/BUILD_TROUBLESHOOTING.md
----------------------------------
把 CI 首次编译实际踩到的 3 个坑完整记录下来，每条都带：
  · 原始错误信息（原样复制，便于搜索）
  · 根因定位（附 Theos / Apple 头文件的相关代码位置）
  · 修法（可直接复制的代码）

1. Theos 不自带 iOS SDK
   macos-latest 运行器上既无 $THEOS/sdks/ 也没有 Xcode 内的
   iPhoneOS SDK，make 在 before-all 阶段就报
   "You do not have any SDKs in ..."。附 theos/sdks 各版本对照表。

2. macOS 自带 bash 3.2 把空数组当未定义变量
   set -u 下 "${empty[@]}" 在 bash 4.4+ 安全、在 3.2 报
   unbound variable。附 bash 3.2 下应避免的语法清单
   （${arr[@]} / ${var,,} / mapfile / 关联数组）。

3. notify_register_check 的 out_token 是 int* 而非 uint32_t*
   （返回值是 uint32_t，参数是 int*，两者不一致，极易看错）

另外记录了两个排查手法：
  · 日志大小作为信号：~450B = make 没跑起来；~1KB = 缺 SDK；
    >4KB = 进了真正编译，看第一条 error
  · Logos 语法可在 Windows 本地预检（Logos 是纯 perl，不需要 iOS SDK），
    含 Git for Windows 缺 Locale::Maketext::Simple 的绕法

Makefile
--------
注释中记录 Logos 生成器的可选开关 LOGOS_DEFAULT_GENERATOR=internal：
默认 MobileSubstrate 生成器会写入
.linker_option "-framework CydiaSubstrate"，Dopamine 的 ElleKit 自带该
兼容层所以默认可用；若链接期报找不到 CydiaSubstrate，改为 internal
即可用纯 ObjC runtime 实现（已用本地 perl 实测：internal 产物中
MSHookMessageEx 与 CydiaSubstrate 引用均为 0）。
