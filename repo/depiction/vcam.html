VCam

系统级虚拟相机 + 虚拟麦克风 · iOS 15.0 – 16.6.1

arm64 / arm64e rootful / rootless ElleKit 无卡密 · 无联网授权

这是什么

VCam 把整机的摄像头画面和麦克风音频替换成虚拟源。任意调用系统相机管线的 App —— 系统相机、FaceTime、微信、QQ、Zoom、Snapchat、Instagram、TikTok —— 看到的都是虚拟内容，而不是物理传感器。

插件在 mediaserverd（相机与音频的真正采集进程）和 App 的 AVFoundation 两层同时注入，所以预览、拍照结果、录像文件 全部都是虚拟画面，音视频唇形同步。

  • 视频：相册视频循环播放；有音轨则同步替换麦克风
  • 图片：相册图片作为静止画面，按约 30fps 重复送帧
  • OBS / 电脑推流：MPEG-TS(H.264+AAC) over UDP/TCP，手机端硬解注入
  • 禁用替换：立刻完整回到硬件相机与硬件麦克风，无残帧残音

怎么用（一分钟）

  1. 安装本包，无需 respring。
  2. 打开任意相机 App，按一次「音量减」。
  3. 在弹出的悬浮小窗里选择：选择视频 / 选择图片 / 电脑推流 / 禁用替换。
  4. 小窗可以拖动、会自动贴边，不阻断当前 App。再按一次音量减可收起。
音量键策略：短按弹窗（并把音量还原，不误调音量）、长按才真正调音量。 系统通话中不拦截音量键。

OBS / 电脑推流 逐步设置

1. 手机端

小窗里点「电脑推流 / OBS」。插件会开始监听并在界面上显示一个完整地址， 例如 udp://192.168.1.20:5600，并且已经帮您复制到剪贴板。

2. 电脑端 OBS

OBS → 设置 → 输出 → 把「输出模式」改成 高级 → 切到 流 标签：

编码器       : FFmpeg 自定义输出  (Custom Output (FFmpeg))
FFmpeg 输出类型 : 输出到 URL
容器格式      : mpegts
视频编码器    : libx264
音频编码器    : aac
输出目标      : udp://192.168.1.20:5600   ← 填手机显示的地址

然后点「开始推流」。

3. 推荐编码参数

参数建议值
分辨率1080x1920（竖屏）/ 1920x1080（横屏）/ 1280x720（省流量）
帧率30 fps（60fps 会明显增加手机解码压力）
编码预设veryfast 或 faster
Profilebaseline 或 main（不要 high 10-bit）
x264 调优tune=zerolatency
关键帧间隔1 秒（keyint=30），越小越容易从丢包恢复
码率Wi-Fi 4–8 Mbps；USB 网络共享 10–15 Mbps
B 帧0（bframes=0），降低延迟

4. 更稳的连接方式（推荐）

用数据线开启 USB 网络共享（iPhone 个人热点用线连接电脑）， 手机上网卡会变成 172.20.10.x，用这个地址推流比 Wi-Fi 延迟低得多，也不容易丢包。小窗会把这类地址排在前面。

常见问题

按音量减没反应

通话中按设计不拦截；另外确认不是长按（长按会调音量）。到 「设置 → VCam → 查看日志」可确认注入状态。

预览是虚拟的，但拍下来是真的

说明 mediaserverd 层的出帧符号在你这版 iOS 上没被 hook 到 （iOS 15 与 16.4+ 的私有符号有变化），并且 App 层的拍照 hook 也被绕过了。 请把日志发出来，并临时到「设置 → VCam」打开「仅 App 层注入」试试。

装了之后相机黑屏 / 相机 App 打不开

到「设置 → VCam」打开「仅 App 层注入」，然后执行 killall mediaserverd 或重启一次。VCam 自带降级保护： 如果 mediaserverd 在注入后异常退出，下次启动会自动切换到 App 层模式。

手机显示「等待 OBS」

地址必须用手机显示的 IP（不能写 127.0.0.1）；端口要和手机一致； 确认电脑与手机在同一网段；UDP 被防火墙拦的话改成 tcp:// 试试。

声音还是真的麦克风

请选择带音轨的视频，或使用 OBS 模式（OBS 里必须同时有音频轨）。 如果只有画面没有音频，VCam 会输出静音占位而不是放行真实麦克风。
