虚拟摄像头

iOS 15.0 – 16.6.1 · 系统级虚拟相机 + 虚拟麦克风

1 添加软件源

在 Sileo 里点「软件源」→ 右上角 + → 粘贴：

https://quite85.github.io/vcam

2 安装

刷新源 → 搜索「虚拟摄像头」→ 安装 → Respring。

⚠️ 添加前请先卸载其它同名插件，避免同名注入文件互相覆盖。

3 使用

  1. 打开系统相机
  2. 短按一下「音量减」→ 弹出悬浮小窗
  3. 点 🎬 选择视频 → 允许相册权限 → 选一个视频
  4. 相机画面立刻切换成该视频（无需杀进程 / respring）

音量键：短按弹窗（音量会自动还原）· 长按才真正调音量 · 通话中不拦截。

功能

  • 相册视频循环替换相机画面（含音轨）
  • 相册图片作为动态静帧
  • 虚拟麦克风：用视频音轨替换真实麦克风
  • 旋转 / 镜像 / 横竖屏 / 循环 / 唇形同步
  • 一键禁用，完整恢复硬件相机与麦克风
  • mediaserverd + AVFoundation 双层注入
